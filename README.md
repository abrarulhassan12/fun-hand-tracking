# 🖐️ Fun Hand Tracking

An interactive hand tracking project built with **HTML, CSS, and JavaScript** that uses your webcam to detect and track hand movements in real time.

## 🚀 Live Demo

🔗 https://abrarulhassan12.github.io/fun-hand-tracking/

## ✨ Features

- 🖐️ Real-time hand tracking
- 📷 Webcam-based interaction
- 🎯 Detects hand movement and position
- 🖥️ Interactive visual effects
- ⚡ Smooth real-time performance
- 🎨 Modern user interface
- 📱 Responsive design
- 🤖 Computer vision powered experience

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Web Camera API
- Hand Tracking Technology
- Computer Vision

## ▶️ How to Run Locally

Clone the repository:

```bash
git clone https://github.com/abrarulhassan12/fun-hand-tracking.git
```

Open the project folder:

```bash
cd fun-hand-tracking
```

Run:

```
index.html
```

Allow camera permission when requested.
